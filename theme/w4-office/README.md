# W4 Office theme

Product: W4 Office. Publisher: W4. Blue: #1463e5. White: #ffffff.
Build with THEME=w4-office and PRODUCT_VERSION set to the parent version.
Vector lettering is original W4 artwork and does not depend on installed fonts.
The theme inherits Euro-Office behaviour and preserves upstream legal notices.
New code: AGPL-3.0-only. New SVG artwork: CC-BY-SA-4.0, Copyright 2026 W4.
This is a development theme; release compliance must include all component licences
and the corresponding source for the actual delivered build.
